# kaikai-daihuo-skill

抖音短视频带货文案写作技能。用户输入商品名称，输出 3 条可直接拍摄、开头/痛点/逼单促单各不相同的单段落高转化带货文案；内置同品类对标、千川敏感词规避、开头验收。用于短视频带货口播文案创作。

## 安装

```bash
npx -y skills add ShaneMX/kaikai-daihuo-skill -g --all
```

## 使用

安装后，可以这样开始：

> 使用 $kaikai-daihuo-skill：给我一个商品名称，我来输出 3 条可直接拍摄的带货文案。

## 运行依赖

- 支持 Agent Skills 的客户端
- Python 3（用于运行 Skill 内脚本）
