# kaikai-daihuo-skill

## 任务与产出

用户提供**商品名称**（投放平台固定为抖音），本技能交付一份由本技能统领的完整结果：

1. **对标结论**：同品类「高转化长什么样」的简短界定（来自对标阶段，公开可核实信息）；
2. **高转化文案怎么写**：直接回答写作方法，提炼说服与转化的可信理论、历史同构案例，给出带条件的标准答案；
3. **文案框架 + 3 条定稿带货文案**：每条包含开头钩子、核心卖点、可信证据、促单行动；**3 条在开头、痛点、逼单促单话术上互不相同**，均为单个完整段落、可直接拍摄；
4. **高转化依据**：为什么这套文案能转化；
5. **开头验收结论**：逐条检查开头是否独立成立、有钩子、有可信度、口播友好；不通过则只重写开头，不推翻核心命题。

最终只交付一份由本技能统领的结果，不拼接多份独立报告。

## 关键不变量

- 用户只需提供商品名称即可开始；平台固定抖音，不询问；
- 最终输出**固定 3 条**文案，每条在开头、痛点、逼单促单话术上互不相同；
- 每条文案**整合成一个完整段落，不换行**；
- **不提明确价格**，只用模糊表述（如「到手两大罐你看看才多少钱」）；
- **不编造数据**：不虚构销量、转化率、好评数；成分、酿造天数等事实口径以包装/实物为准；
- 对标和引用的事实必须**可核实、用公开信息**；
- 硬性写作约束与千川投流敏感词（见「硬性写作约束」和 `references/qianchuan-sensitive-words.md`）对**全部 3 条文案**生效。

## 输入与最少提问

- **必需输入**：商品名称。
- 商品名称过笼统、无法确定品类或 SKU 时（如只给「饼干」），最多追问 1 次，请用户补充具体产品名或卖点。
- 可选输入（不齐不阻塞）：卖点、实拍素材、活动机制、包装成分。缺失时用**标注的暂定假设**继续，定稿前请用户按包装校准。
- 不需要：平台（固定抖音）、价格（禁止写明确价格）、转化数据（禁止编造）。

## 工作流程（顺序固定：对标 → 写作方法与文案 → 开头验收）

### 阶段 1：对标（证据补充，写文案之前）

1. 用五重过滤法检索同品类真实、高转化、可模仿的带货视频 / 文案对标，方法见 `references/benchmark-five-filter.md`；
2. 归纳该品类高转化共性（开头结构、信任证据、促单方式），输出简短对标结论；
3. **找不到合格对标时，降级为通用高转化结构（见 `references/high-conversion-framework.md`）并说明原因**。

### 阶段 2：写作方法与文案（主流程，最终交付）

1. 先直接回答「高转化带货文案怎么写」：结合说服与转化理论、历史同构案例，提炼带条件的标准答案，见 `references/high-conversion-framework.md`；
2. 产出文案框架：**开头钩子 → 痛点共鸣 → 核心卖点 → 可信证据 → 促单行动**；
3. 产出 **3 条定稿文案**：从开头类型、痛点类型、逼单类型中各取不同组合（参考 `references/high-conversion-framework.md` 的组合表），确保 3 条互不相同；
4. 每条文案用 `scripts/check_sensitive_words.py` 过检，命中敏感词必须改写后再交付。

### 阶段 3：开头验收（验收约束，定稿前）

1. 对每条文案的开头按 `references/opening-acceptance.md` 四项标准检查：独立成立、有钩子、有可信度、口播友好；
2. 任一不通过：**只重写开头**，保留核心命题、卖点与促单，并给出优化开头与原因；
3. 输出验收结论。

## 硬性写作约束（全部 3 条文案必须遵守）

**A. 基本格式**
1. 不提明确价格，只用模糊表述（如「到手两大罐你看看才多少钱」）；
2. 整合成一个完整段落输出，不要换行。

**B. 表达风格**
3. 种草语气、口语分享感，去 AI 味；
4. 痛点必须真实、符合日常逻辑，不许编戏；
5. 忌绝对化与夸大（不用「最」「第一」等）；
6. 铺垫要短，开头快速进入正题；
7. 多条文案：每条不同卖点 + 不同促单，避免雷同。

**C. 事实口径**
8. 成分、酿造天数等以包装/实物为准，不虚构数据和转化数字；
9. 限制类目避开功效词（如私密洗液不提抑菌、消炎），不碰医疗功效场景（如儿童电解质水不涉医疗功效）。

**D. 千川投流敏感词**
完整清单与替换建议见 `references/qianchuan-sensitive-words.md`。核心类别：0/无添加类（0蔗糖、0添加、零添加、无添加、无糖、零糖、纯天然、「配料表干干净净」→ 换「配料表也很简单」）、绝对化/极限词、医疗/功效词、虚假承诺/无依据数据、权威背书类。

## 事实与降级规则

- 对标和引用的事实需可核实，只用公开信息，不虚构销量 / 转化率；
- 找不到合格对标 → 降级为通用高转化结构并说明原因；
- 开头验收不通过 → 只修改开头，不推翻核心命题；
- 成分、质地、活动机制等未核实信息 → 标注「待校准假设」，请用户按包装确认，不默认成事实。

## 停止条件

- 已交付 3 条过检文案 + 高转化依据 + 开头验收结论；
- 商品名称缺失且追问 1 次后仍未提供 → 停止并说明需要商品名称；
- 用户明确要求停止或只要求方案说明。

## references / scripts 使用条件

- `references/benchmark-five-filter.md`：阶段 1 对标时读取；
- `references/high-conversion-framework.md`：阶段 2 写作时读取（含理论、案例、框架与组合表）；
- `references/opening-acceptance.md`：阶段 3 验收时读取；
- `references/qianchuan-sensitive-words.md`：每条文案定稿前核对；
- `scripts/check_sensitive_words.py`：对每条定稿文案运行，命中即改写；
- `references/install-guide.md`：面向小白用户的豆包安装与更新说明（分发给用户时使用）。
