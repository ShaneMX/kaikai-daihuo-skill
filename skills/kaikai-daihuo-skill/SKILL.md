# kaikai-daihuo-skill

## 任务与产出

用户提供**商品名称**（投放平台固定为抖音），本技能交付一份由本技能统领的完整结果，按**固定六部分结构**输出（模板见 `references/output-format.md`，完整示例见 `references/example-zhaohui.md`）：

1. **最终推荐文案（30 秒，可直接拍摄）**：按黄金三段式分时间行的表格（时间 | 画面/拍摄提示 | 口播）+ 配套拍摄要点；
2. **文案结构图**：黄金三段式结构图；
3. **可复用文案框架**：黄金三段式一句式 + 本品卖点清单；
4. **另两个可替换原型**：不同开头 / 痛点 / 逼单组合的口播段落；
5. **高转化依据**：对标结论（五重过滤 + 反例警示）、理论依据、历史同构与带条件标准答案；
6. **开头验收**：维度表格（独立性 / Hook / 悬念 / 可信度 / 口播友好 / 匹配度）+ 备选开头。

最终只交付一份由本技能统领的结果，不拼接多份独立报告。

## 关键不变量

- 用户只需提供商品名称即可开始；平台固定抖音，不询问；
- 最终交付固定为上述**六部分结构**；
- 推荐文案与 2 个原型在**开头、痛点、逼单促单话术上互不相同**；
- 口播连起来是连续口播（表格单元格内不换行），原型为单个完整段落；
- **价格**：价格锚点层写入**用户提供的实际活动价**；未提供时标注「暂定假设，以实际活动价为准」，不编造价格；
- **不编造数据**：不虚构销量、转化率、好评数；成分、酿造天数等事实口径以包装/实物为准；
- 对标和引用的事实必须**可核实、用公开信息**；
- 硬性写作约束与千川投流敏感词（见「硬性写作约束」和 `references/qianchuan-sensitive-words.md`）对**全部文案**生效。

## 输入与最少提问

- **必需输入**：商品名称。
- 商品名称过笼统、无法确定品类或 SKU 时（如只给「饼干」），最多追问 1 次，请用户补充具体产品名或卖点。
- 可选输入（不齐不阻塞）：**活动价**（价格锚点层需要，未提供则标注暂定假设）、卖点、实拍素材、活动机制、包装成分。缺失时用**标注的暂定假设**继续，定稿前请用户按实物校准。
- 不需要：平台（固定抖音）、转化数据（禁止编造）。

## 工作流程（顺序固定：对标 → 写作方法与文案 → 开头验收）

### 阶段 1：对标（证据补充，写文案之前）

1. 用五重过滤法检索同品类真实、高转化、可模仿的带货视频 / 文案对标，方法见 `references/benchmark-five-filter.md`；
2. 归纳该品类高转化共性（开头结构、信任证据、促单方式），输出简短对标结论；
3. **找不到合格对标时，降级为通用高转化结构（见 `references/high-conversion-framework.md`）并说明原因**。

### 阶段 2：写作方法与文案（主流程，最终交付）

1. 先直接回答「高转化带货文案怎么写」：结合说服与转化理论、历史同构案例，提炼带条件的标准答案，见 `references/high-conversion-framework.md`；
2. 产出文案框架：**黄金三段式（0-3s 钩子层 → 3-25s 价值实证层 → 25-30s 转化收口层）**，对应元素为开头钩子 → 痛点共鸣 → 核心卖点 → 可信证据 → 促单行动；分层结构与信任红线见 `references/high-conversion-framework.md`，结构图见 `assets/copy-structure-golden-three-stage.png`；
3. 按 `references/output-format.md` 六部分结构产出**最终推荐文案（表格）+ 2 个可替换原型**：推荐文案与原型在开头、痛点、逼单类型上取不同组合（参考 `references/high-conversion-framework.md` 的组合表），确保互不相同；
4. 全部口播文案用 `scripts/check_sensitive_words.py` 过检，命中敏感词必须改写后再交付。

### 阶段 3：开头验收（验收约束，定稿前）

1. 对推荐文案与 2 个原型的开头按 `references/opening-acceptance.md` 标准检查：独立成立、有钩子、有可信度、口播友好（并按 `references/output-format.md` 的六维表格输出）；
2. 任一不通过：**只重写开头**，保留核心命题、卖点与促单，并给出优化开头与原因；
3. 输出验收结论与备选开头。

## 硬性写作约束（全部文案必须遵守）

**A. 基本格式**
1. 价格锚点层写入**用户提供的实际活动价**（如「39.9 到手 2 罐」）；未提供时标注「暂定假设，以实际活动价为准」；不编造价格；
2. 口播连起来是一段可连续朗读的口播（表格单元格内不换行）；原型 2 / 3 为单个完整段落。

**B. 表达风格**
3. 种草语气、口语分享感，去 AI 味；
4. 痛点必须真实、符合日常逻辑，不许编戏；
5. 忌绝对化与夸大（不用「最」「第一」等）；
6. 铺垫要短，开头快速进入正题；
7. 多条文案：每条不同卖点 + 不同促单，避免雷同。

**C. 事实口径**
8. 成分、酿造天数等以包装/实物为准，不虚构数据和转化数字；
9. 限制类目避开功效词（如私密洗液不提抑菌、消炎），不碰医疗功效场景（如儿童电解质水不涉医疗功效）。

**D. 千川投流敏感词**
完整清单与替换建议见 `references/qianchuan-sensitive-words.md`。核心类别：0/无添加类（0蔗糖、0添加、零添加、无添加、无糖、零糖、纯天然、「配料表干干净净」→ 换「配料表也很简单」）、绝对化/极限词、医疗/功效词、虚假承诺/无依据数据、权威背书类。

## 事实与降级规则

- 对标和引用的事实需可核实，只用公开信息，不虚构销量 / 转化率；
- 找不到合格对标 → 降级为通用高转化结构并说明原因；
- 开头验收不通过 → 只修改开头，不推翻核心命题；
- 成分、质地、活动机制等未核实信息 → 标注「待校准假设」，请用户按实物确认，不默认成事实；
- 用户未提供活动价 → 价格锚点层标注暂定假设，不编造。

## 停止条件

- 已交付六部分完整结果（推荐文案 + 2 原型 + 依据 + 验收）；
- 商品名称缺失且追问 1 次后仍未提供 → 停止并说明需要商品名称；
- 用户明确要求停止或只要求方案说明。
