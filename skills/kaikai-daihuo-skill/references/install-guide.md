# 安装与更新说明（给小白用户）

本技能在豆包内使用，**不需要任何代码**。安装一次，电脑和手机都能用。

## 一、标准安装（电脑 / 网页版，约 1 分钟）

1. 电脑打开豆包网页版（doubao.com）或电脑客户端，登录你的账号；
2. 左侧找到「技能·连接器·伙伴」→「我的技能」→ 右上角「上传技能」；
3. 把 `kaikai-daihuo-skill` 文件夹（或收到的压缩包解压后的文件夹）**拖进上传框**，等待提示完成；
4. 完成。手机豆包登录同一账号后，直接可用。

> 如果拿到的是「分享入口 / 分享口令」，在豆包网页版里点击或输入即可一键添加。

## 二、手机安装方案

**重要说明**：豆包手机 App 没有「上传技能」入口（官方产品限制），但有两种手机可用方案：

### 方案 A：手机浏览器网页版上传（纯手机操作，推荐先试）

1. 手机浏览器打开 `doubao.com`，登录你的账号；
2. 若显示的是手机版页面，先切换为「电脑版网页」（浏览器菜单里选「桌面版网站 / 请求桌面站点」）；
3. 进入「工作」模式 →「技能·连接器·伙伴」→「我的技能」→「上传技能」；
4. 选择技能包：把收到的压缩包在手机文件管理里解压，上传时选中 `kaikai-daihuo-skill` 文件夹；
5. 完成后，手机豆包 App 登录同一账号直接可用。

> 注意：部分手机浏览器不支持「选择文件夹」，只能选单个文件，此时上传会失败——改用方案 B，或把解压后的文件夹先传到电脑再上传。

### 方案 B：任意设备装一次，手机直接用（最稳妥）

1. 在任意一台电脑（或借用的电脑）打开 doubao.com，登录你的账号；
2. 按「一、标准安装」上传一次技能（约 1 分钟）；
3. 手机豆包 App 登录**同一个账号**，无需任何操作，直接可用。

### 方案 C：零安装应急（手机 App 直接对话使用，功能精简）

如果暂时装不了，可以在手机豆包对话里粘贴一段「带货文案指令」直接使用（由制作者提供）。能产出 3 条文案，但缺少对标检索和敏感词脚本校验等完整能力，建议仍按方案 A / B 安装完整版。

## 三、使用

- 电脑或手机豆包对话中，输入商品名称即可，例如：`洛蕾诗蔓越莓女性私密洗液`；
- 也可以输入 `/kaikai-daihuo-skill` 再跟上商品名；
- 技能会自动输出 3 条可直接拍摄的带货文案（单段落、不提明确价格、避开敏感词）。

## 四、更新到新版本

1. 拿到新版本（新压缩包或新的分享入口）；
2. 电脑端「技能管理」→ 找到本技能 → 重新上传 / 覆盖安装同名技能；
3. 手机端无需操作，自动使用新版本。

## 五、常见问题

- **找不到上传按钮**：确认用的是豆包网页版 / 电脑客户端最新版；手机 App 没有该入口。
- **手机浏览器选不了文件夹**：切换「电脑版网页」重试，或改用方案 B。
- **提示格式不对**：确认上传的是文件夹本身（内含 SKILL.md），不要只上传单个文件。
- **手机端不能上传**：这是豆包产品限制，用网页版 / 电脑端上传一次即可，手机端直接用。
