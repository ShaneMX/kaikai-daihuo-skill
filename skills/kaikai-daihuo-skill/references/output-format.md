# 最终交付格式（输出模板）

每次运行按以下**六部分**顺序交付，结构固定，内容随商品变化。完整示例见 `example-zhaohui.md`。

## 标题

`{商品名}・抖音高转化带货文案（最终交付）`

开头先列**暂定假设**（用户未提供的推断信息，如目标人群、场景、价格口径），并注明「以实际活动价 / 实物为准，若不同直接替换」。

## 一、最终推荐文案（30 秒，可直接拍摄）

表格，列：**时间 | 画面（拍摄提示）| 口播**，行按黄金三段式分层：

| 时间 | 画面（拍摄提示） | 口播 |
|---|---|---|
| 0-3s | 产品怼脸特写、拆封瞬间 | 反差一句话圈人（反差 + 悬念 + 品牌背书） |
| 3-8s | 动作特写（倒 / 撕 / 摇 / 戴手套…） | 口播动作，画面自带看点 |
| 8-18s | 试吃 / 使用特写（出声、表情享受） | 实证体验，声音表情证明好吃好用 |
| 18-25s | 展示整罐 + 配料表 / 大小对比；字幕价格 | 价格锚点 + 赠品，制造超值感 |
| 25-30s | 手指小黄车；字幕「点小黄车」 | 明确指令促单 + 低决策门槛 |

**配套拍摄要点**（3～5 条）：关键动作给近景、试吃必须收音、真实展示不夸大分量等。

## 二、文案结构图

引用黄金三段式结构图（`assets/copy-structure-golden-three-stage.png`）或输出同构结构说明。

## 三、可复用文案框架

- 黄金三段式（30 秒）一句话：钩子层（3s 反差 / 痛点圈人）→ 价值层（22s 动作演示 + 试吃实证 + 卖点交叉）→ 收口层（5s 价格锚点 + 赠品 + 明确指令）；
- 本品卖点清单（3～5 个）：如反差创新、互动玩法、双重体验、使用场景、超值组合。

## 四、另两个可替换原型

- **原型 2**：与推荐文案不同开头 / 痛点 / 逼单组合（如场景痛点向）；
- **原型 3**：再换一组组合（如真实测评向 / 信任向）；
- 每条为单个完整段落口播，3～5 句。

## 五、它为什么高转化（依据）

1. **对标结论**（五重过滤）：同品类真实高转化对标 + 反例警示（如夸大被测评点名）；
2. **理论依据**：千川素材逻辑（钩子 1 秒筛人 + 2 秒戳痛 / 价值实证 + 素人口播 / 收口低门槛）+ Cialdini 六原则映射 + AIDA 映射 + 感官机制（ASMR、互动仪式）；
3. **历史同构与标准答案（带条件）**：同构案例（同品牌系列化打法、电视购物、头部主播）+ 失败边界 + 带条件的标准答案。

## 六、开头验收

表格：**维度 | 结果 | 说明**，维度为独立性 / Hook / 悬念 / 可信度 / 口播友好 / 匹配度（承诺在正文兑现）；附 2 个备选开头（只替换第 1 句）。

## 规则提醒

- 价格锚点层写入**用户提供的实际活动价**；未提供时标注「暂定假设，以实际活动价为准」，不编造价格；
- 分量 / 数量展示必须真实，不夸大；
- 口播列连起来是连续口播，单元格内不换行；原型 2 / 3 为单个完整段落；
- 其余硬性约束（敏感词、功效词、事实口径、开头验收通过才交付）不变。
