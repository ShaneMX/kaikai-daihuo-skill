# 最终交付格式（输出模板）

每次运行按以下**七部分**顺序交付，结构固定，内容随商品变化。完整示例见 `example-zhaohui.md`。

## 标题

`{商品名}・抖音高转化带货文案（最终交付）`

开头先列**暂定假设**（用户未提供的推断信息，如目标人群、场景），并注明「以实物 / 包装为准，若不同直接替换」。不写价格假设，价格一律模糊表述。

## 一、对标结论（简短）

该品类「高转化长什么样」：`{开头结构} + {信任证据} + {促单方式}`，附公开对标来源；找不到合格对标时说明已降级为通用结构。

## 二、高转化文案怎么写（写作方法）

直接回答 + 可信理论 + 历史同构案例 + 带条件的标准答案（要点见 `high-conversion-framework.md`），两三段内讲清。

## 三、文案框架 + 3 条定稿文案（最终交付主体）

- **文案框架**：黄金三段式（3s 钩子 → 22s 价值实证 → 5s 转化收口）一句话 + 本品卖点清单（3～5 个）；
- **3 条定稿文案**：从开头类型、痛点类型、逼单类型各取不同组合（见 `high-conversion-framework.md` 组合表），确保 3 条在开头、痛点、逼单促单上互不相同；每条为**单个完整段落、不换行、不提明确价格**；
- 每条文案用 `scripts/check_sensitive_words.py` 过检后交付。

## 四、文案结构图（黄金三段式）

基于**文案一（推荐条）**生成结构图（用户指定其他条时按指定条）：顶部拍摄要点条 → 标题与副标题（黄金三段式）→ 三层表头（钩子/价值/收口）→ 5 个时间分槽卡片（时间标签、动作内容、文案摘录、作用）→ 底部 5 大卖点 + 信任红线 + 口径备注。版式与映射规则见 `structure-diagram.md`，以 HTML/SVG renderer 输出。

## 五、高转化依据

1. 对标结论（五重过滤 + 反例警示）；
2. 理论依据：千川素材逻辑 / Cialdini 六原则 / AIDA / 感官机制（简要映射）；
3. 历史同构与标准答案（带条件）：同构案例 + 失败边界 + 带条件的标准答案。

## 六、开头验收

对 3 条文案的开头逐条按四项标准检查（独立成立 / 有钩子 / 有可信度 / 口播友好），输出结论；不通过只重写开头并给出优化开头。

## 七、拍摄分镜表（用户要求时）

用户要求拍摄提示时，为每条文案附 30 秒分镜表，列：**时间 | 镜头/景别 | 画面内容 | 拍摄提示**，并标注该品关键字幕词（如「减盐25%」「180天传统酿造」）。

## 规则提醒

- 不提明确价格，只用模糊表述（如「到手两大罐你看看才多少钱」）；
- 每条文案整合成一个完整段落，不换行；
- 全部文案过千川敏感词检测（`references/qianchuan-sensitive-words.md`），命中即改写；
- 分量 / 数量展示必须真实，不夸大（夸大实物会被测评反噬）；
- 限制类目避开功效词与医疗场景；
- 其余硬性约束（事实口径、开头验收通过才交付）不变。
