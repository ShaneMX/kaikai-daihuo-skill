# 文案结构图（黄金三段式）生成规范

根据**已定稿的文案**生成「30 秒高转化文案结构图」：把一条口播文案拆进时间分槽，输出一张静态 HTML/SVG 结构图（对话内 renderer 渲染），让用户一眼看清文案的转化骨架。

## 何时生成

- 标准交付的一部分：默认基于**文案一（推荐条）**生成；
- 用户指定其他条（「给文案二也出图」）时，按指定条生成，每条一张；
- 用户上传结构图示例要求复刻版式时，按本规范的版式与内容规则输出。

## 版式（自上而下 5 块，复刻已验证示例）

1. **顶部拍摄要点条**：2～4 条，来自文案里的动作/画面（如「摇罐动作给近景」「试吃必须收音」）；
2. **标题 + 副标题**：`{商品名}·30秒高转化文案结构`；副标题 `黄金三段式 = 3秒钩子筛选 → 22秒价值实证 → 5秒转化收口`；
3. **三层表头**：钩子层（0-3s·筛选人群）｜价值输出层（3-25s·证明值得买）｜转化收口层（25-30s·推动下单）；
4. **5 个时间分槽卡片**（0-3s / 3-8s / 8-18s / 18-25s / 25-30s），每卡四行：时间标签、动作内容、**文案摘录（原句，可截断加省略号）**、作用说明；
5. **底部信息区**：5 大转化卖点（横向 chips）+ ⚠️ 信任红线（本品特定）+ 口径备注。

## 文案→分槽映射规则

| 槽 | 文案来源 | 作用说明模板 |
|---|---|---|
| 0-3s 钩子层 | 首句钩子 | 反差/痛点/点名人群，1秒筛人 |
| 3-8s 价值层 | 动作/玩法句 | 动作特写，画面自带看点 |
| 8-18s 价值层 | 体验/实证句 | 用声音和表情证明好吃好用（或数据实证） |
| 18-25s 价值层 | 价格锚点句 | **只放模糊价格表述**（「你们看看这个价」「到手两大罐」），配赠品/比价制造超值感 |
| 25-30s 收口层 | 促单句 | 行动指令 + 低决策门槛 |

**硬约束**：
- 图内文案摘录沿用定稿原文，**不得出现明确价格数字**（与文案规则一致）；内部成本/活动价只允许出现在「口径备注」里并注明「以实际活动价为准」；
- 摘录必须来自已过敏感词检测的定稿文案，图内不新增任何营销词；
- 信任红线来自该品真实风险（分量夸大被打假、限制类目功效词、儿童/母婴医疗表述等），不编造。

## 渲染规范（遵循 doubao-visualization html_svg 静态模式）

- 输出 ` ```html type="renderer"` 代码块；禁 `<!DOCTYPE>`/`<head>`/`<body>`；CSS 全部内联；
- 根容器自然撑高，`width:100%;box-sizing:border-box`；多列弹性换行，窄屏不溢出；
- 三层用三色区分（钩子红橙 / 价值蓝 / 收口绿），**必须同时用文字标签**（层名+时间）而非只靠颜色；
- 正文不低于 14px；静态无脚本；不加装饰动画；
- 内容全部来自定稿文案与已核实事实，示意性文字（如「示意」）按需标注。

## 质量自检

- 五个槽是否完整、时间标签与层对应正确？
- 摘录是否原句、无明确价格、无敏感词？
- 底部卖点是否与文案主打卖点一致、不超 5 个？
- 信任红线与口径备注是否本品特定且可核实？
