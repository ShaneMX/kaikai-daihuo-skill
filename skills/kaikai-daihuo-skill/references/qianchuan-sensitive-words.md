# 千川投流敏感词清单（文案中必须避免）

每条定稿文案交付前，用 `../scripts/check_sensitive_words.py` 过检。命中即改写，不得保留。

## 1. 0 / 无添加类（食品与日化重灾区）

| 禁用 | 替换建议 |
|---|---|
| 0蔗糖、0添加、零添加、0防腐剂、0色素 | 「配料表也很简单」「成分表很干净（以包装为准）」 |
| 无添加、没有添加、不含添加剂、无任何添加剂 | 不主动声称，以包装配料表为口径 |
| 无糖、零糖、低糖（高风险） | 「不齁甜」「甜度刚刚好」（以包装为准） |
| 纯天然、天然无添加 | 「配料表也很简单」（以包装为准） |
| 配料表干干净净 | 「配料表也很简单」 |

## 2. 绝对化 / 极限词

最、最佳、最好、最低、最高、第一、全网第一、全国第一、销量第一、唯一、首个、首选、顶级、极致、巅峰、王牌、冠军、国家级、世界级、天花板、独家、首发、绝无仅有、史无前例、万能、永久、100%、100%有效、零风险、零差评、必备、性价比之王、全网最低价、地板价、绝对、彻底、永不反弹、特效、神器

## 3. 医疗 / 功效词（非医疗产品一律禁用）

治疗、疗效、根治、治愈、预防、防治、康复、改善、调节、养颜、排毒、消炎、杀菌、抑菌、抗菌、止痒、去味（功效义）、增强免疫、提高抵抗力、延年益寿、减肥、瘦身、燃脂、降血糖、降血脂、降压、抗癌、防癌、助眠、安神、补脑、护肝、修复敏感肌（普通产品）

限制类目特别注意：私密洗液不提抑菌、消炎、止痒、妇科问题；儿童饮品不提医疗功效、不提「增强体质」类表述。

## 4. 虚假承诺 / 无依据数据

无证据的销量、好评率、转化率数字；假一赔十、无效退款、保险赔付、包治包好、绝对有效。

## 5. 权威背书类（无资质不得使用）

国家推荐、国家机关推荐、特供、专供、央视上榜、CCTV、无资质的「老字号」「驰名商标」「官方认证」。

## 6. 其他规避

- 谐音字、拼音、错别字规避审核（如「最→醉」）同样违规，不使用；
- 专利、检测报告等需以真实资质为准，未核实不得声称。

## 使用说明

- 本清单为最低红线，平台规则会更新，实际投放以最新审核口径为准；
- 不确定是否违规的词，宁可替换为事实性表述；
- 改写后必须重新运行 `check_sensitive_words.py` 确认无命中。
