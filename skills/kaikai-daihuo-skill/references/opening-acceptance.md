# 开头验收标准（阶段 3 定稿前执行）

对每一条文案的开头（第一句话）逐项检查。四项全部通过才算合格。

## 四项检查

| 检查项 | 通过标准 | 失败例子 |
|---|---|---|
| ① 独立成立 | 单看这一句就能成立，不依赖前情 | 「还有上次说的那个」 |
| ② 有钩子 | 制造疑问 / 反差 / 点名人群，让人想听下去 | 「今天给大家推荐一个东西」 |
| ③ 有可信度 | 真实场景、日常逻辑、不夸大不编戏 | 「用了它三天就……」（编戏） |
| ④ 口播友好 | 短句、口语、无长难句，3 秒内能读完 | 一句超过 40 字、书面语堆砌 |

## 处理规则

- 任一不通过：**只重写开头**，保留核心命题、卖点、可信证据与促单，不推翻整条文案；
- 重写后重新过四项检查，并给出优化开头与原因；
- 3 条文案的开头之间也要互不相同（与差异化组合一致）。

## 输出

- 每条文案的开头验收结论（通过 / 重写及原因）；
- 若重写，附优化开头。
