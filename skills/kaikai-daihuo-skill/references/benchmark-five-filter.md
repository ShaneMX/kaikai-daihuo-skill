# 五重过滤法：找同品类真实、高转化、可模仿的对标

在写文案之前执行。目标是界定「这个品类的高转化长什么样」，为文案提供可核实的事实依据，而不是虚构转化数据。

## 检索来源

- 抖音公开带货视频 / 直播间切片（可访问链接优先）；
- 抖音电商学习中心、巨量引擎规则中心的官方案例与内容规范；
- 同类目达人、品牌账号的高赞带货内容。

## 五重过滤

| 过滤 | 要回答的问题 | 不合格就剔除 |
|---|---|---|
| ① 品类匹配 | 与本品类受众、价格带、使用场景一致吗？ | 只做近品类或跨品类参考，不当作直接对标 |
| ② 真实可核 | 内容公开可访问、可溯源吗？ | 无法给出来源的「听说很好」不算 |
| ③ 高转化信号 | 结构被大量复用 / 仿写，或有官方案例收录，或互动表现好？ | 孤例、无任何转化信号 |
| ④ 可模仿性 | 结构（话术、节奏、信任证据、促单方式）可以直接套用吗？ | 依赖不可复制的资质、名人、独家供应链 |
| ⑤ 主体差异排除 | 剔除与本品类受众、价格带、合规资质不匹配的对标 | 资质不同的（如消字号 vs 妆字号）分开处理 |

## 执行步骤

1. 按品类关键词检索，收集 5～10 个候选；
2. 用五重过滤粗筛，保留 3～5 个合格对标；
3. 精读合格对标，拆出：开头结构、信任证据、卖点呈现、促单方式；
4. 归纳共性，输出对标结论：**该品类高转化 = {开头结构} + {信任证据} + {促单方式}**；
5. 在最终交付中列出对标来源链接（公开可核），并注明不虚构任何销量 / 转化率数字。

## 降级规则

找不到合格对标（候选不足 3 个或全部被过滤）时：

- 使用 `high-conversion-framework.md` 的通用高转化结构；
- 在交付中明确说明「未找到合格同品类对标，已降级为通用结构」及原因；
- 不为了凑对标而虚构来源或数据。
